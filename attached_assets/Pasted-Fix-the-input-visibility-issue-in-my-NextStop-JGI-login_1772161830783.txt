Fix the input visibility issue in my NextStop JGI login page.

PROBLEM:
In light theme, when entering USN and password, the text is not visible.
In dark theme, it works correctly.

CAUSE:
Input text color is likely set to white globally, causing white text on white background in light mode.

-----------------------------------------
GOAL
-----------------------------------------
1. Make input text clearly visible in light theme.
2. Keep dark theme working properly.
3. Fix placeholder visibility.
4. Fix Chrome autofill color issue.
5. Do NOT break existing layout or styling.
6. Apply consistent theme-aware styling across all forms.

-----------------------------------------
IF USING TAILWIND CSS
-----------------------------------------

Replace any:
text-white

With theme-aware classes:

bg-white text-gray-900
dark:bg-gray-800 dark:text-white
border border-gray-300 dark:border-gray-600
placeholder-gray-400 dark:placeholder-gray-500

Add focus styling:
focus:outline-none focus:ring-2 focus:ring-blue-500

Example correct input styling:

class="w-full px-4 py-2 rounded-md
bg-white text-gray-900
dark:bg-gray-800 dark:text-white
border border-gray-300 dark:border-gray-600
placeholder-gray-400 dark:placeholder-gray-500
focus:outline-none focus:ring-2 focus:ring-blue-500"

-----------------------------------------
IF USING NORMAL CSS
-----------------------------------------

Ensure:

input {
  background-color: white;
  color: #111;
}

.dark input {
  background-color: #1f2937;
  color: white;
}

Remove any global:
input { color: white; }

-----------------------------------------
FIX CHROME AUTOFILL ISSUE
-----------------------------------------

Add:

input:-webkit-autofill {
  -webkit-text-fill-color: #111 !important;
  transition: background-color 9999s ease-in-out 0s;
}

.dark input:-webkit-autofill {
  -webkit-text-fill-color: white !important;
}

- Only fix visibility and ensure proper contrast.
- Apply fix to USN and password fields.
- Ensure accessibility contrast compliance.

Apply changes incrementally.
