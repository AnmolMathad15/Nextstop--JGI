I am building a production-quality college bus tracking platform called "NextStop JGI".

Tech Stack
------------
Frontend:
- React 18
- TypeScript
- Socket.io Client
- React Query
- React Toastify
- MapLibre GL JS

Backend
------------
- Node.js
- Express
- Socket.io
- TypeScript
- PostgreSQL
- Turf.js
- Haversine calculations
- OSRM Route Matching
- Redis (optional for scaling)

Goal
------------
Build an intelligent notification engine similar to Uber, Ola and Google Maps.

The system should never rely only on straight-line GPS distance.

Instead it must combine:

• GPS position
• Road snapped position
• Route progress
• Average speed
• Current speed
• Stop geofences
• ETA prediction
• Notification history

==================================================
STEP 1
Route Progress Engine
==================================================

After GPS arrives,

1. Snap GPS onto the actual bus route using OSRM Map Matching.

2. Find

currentSegment

currentDistanceAlongRoute

remainingDistanceToNextStop

instead of using straight-line distance.

==================================================
STEP 2
ETA Engine
==================================================

Calculate ETA using

ETA =
Remaining Route Distance
/
Average Moving Speed

Average speed should be computed from the previous 60 seconds instead of instantaneous GPS speed.

If speed becomes unrealistic

<5 km/h
or
>80 km/h

ignore it and use rolling average.

STEP 6
Speed Prediction
==================================================

Maintain

rollingAverageSpeed

lastHeading

lastTimestamp

Ignore GPS jumps.

Smooth GPS using Kalman Filter or Moving Average.

==================================================
STEP 7
Driver Validation
==================================================

Reject GPS if

speed >120 km/h

jump >250m in 2 sec

heading changes unrealistically

accuracy >50m

If suspicious

mark GPS as unreliable

and continue using previous predicted position.
