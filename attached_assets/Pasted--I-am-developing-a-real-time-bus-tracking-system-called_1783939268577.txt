"I am developing a real-time bus tracking system called 'NextStop JGI' in React 18 with a Node.js backend. I need to build a two-part module for accurate GPS tracking:Driver Tracking Module: Create a React component for the driver that uses the browser Geolocation API with enableHighAccuracy: true. It should watch the driver's position and, every 10–15 seconds, emit the latitude, longitude, and timestamp to a Socket.io server. Please include logic to ensure the browser prompts for location permission and handles potential GPS signal errors gracefully.  Real-time Distribution Module: Provide the server-side Socket.io code to receive these location updates from the driver and broadcast them to a specific 'room' (based on the routeId) so that all connected students and the admin can receive the live data.  Frontend Display for Students/Admin: Provide a React snippet that listens for these socket events and updates the Mapbox marker's position on the student/admin map.Best Practices: Please include code for 'smoothing' the marker movement so it doesn't jump instantly, and explain how to implement a basic 'Map Matching' logic to ensure the marker stays on the road path defined in my GeoJSON data".  Technical Considerations for your Implementation:Battery & Performance: While you requested 10–15 second updates, ensure your backend uses WebSockets (Socket.io) for this. Standard HTTP polling at that frequency will cause unnecessary server overhead.  Data Integrity: Because GPS data can be noisy (showing the bus in a building), use the Mapbox coordinates from your pre-defined GeoJSON files to validate or "snap" the incoming GPS points to the correct road geometry.  State Management: In your student-facing app, keep the "current bus location" in a dedicated state variable. When a new socket update arrives, use a library like framer-motion or Mapbox's built-in flyTo or easeTo methods to animate the marker from the old coordinate to the new one, creating the "Uber-like" smooth tracking experience.
