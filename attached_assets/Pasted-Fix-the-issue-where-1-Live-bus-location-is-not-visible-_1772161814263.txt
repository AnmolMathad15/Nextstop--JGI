Fix the issue where:

1. Live bus location is not visible on map.
2. Custom markers (bus and JGI logo) are not rendering.
3. Replit says implemented but visually nothing appears.

IMPORTANT:
Do NOT redesign the map.
Do NOT break existing Route → Stop → Map workflow.
Only debug and fix marker rendering.

----------------------------------------
STEP 1: VERIFY ICON PATHS
----------------------------------------

Ensure icons exist in:

public/icons/yellow-bus.png
public/icons/jgi-logo.png

If using React/Vite:
Use:
import busIconImg from "/icons/yellow-bus.png"

If using normal HTML:
Use:
"/icons/yellow-bus.png"

Log image loading error if path fails.

----------------------------------------
STEP 2: FIX MARKER CREATION
----------------------------------------

Ensure markers are created only AFTER map is initialized.

Example:

const busIcon = L.icon({
  iconUrl: "/icons/yellow-bus.png",
  iconSize: [50, 50],
  iconAnchor: [25, 25]
});

if (!window.busMarker) {
  window.busMarker = L.marker([lat, lng], { icon: busIcon }).addTo(map);
}

----------------------------------------
STEP 3: FIX LIVE UPDATE
----------------------------------------

When WebSocket updates:

if (window.busMarker) {
  window.busMarker.setLatLng([newLat, newLng]);
}

Do NOT recreate marker every update.

----------------------------------------
STEP 4: ENSURE MAP IS NOT COVERED
----------------------------------------

Check CSS:

#map {
  height: 100%;
  width: 100%;
}

Ensure no z-index layer hides markers.

----------------------------------------
STEP 5: DEBUG LOCATION
----------------------------------------

Add console logs:

console.log("Bus location:", lat, lng);

If logs are printing but marker not moving:
Problem is marker reference.

If logs not printing:
Problem is WebSocket.

----------------------------------------
STEP 6: ENSURE LEAFLET CSS IS IMPORTED
----------------------------------------

Make sure:

import "leaflet/dist/leaflet.css";

Without this markers sometimes invisible.

----------------------------------------
EXPECTED RESULT
----------------------------------------

- Yellow bus marker visible.
- JGI logo visible at college.
- Bus moves when location updates.
- No duplicate markers.
- No blank map.
