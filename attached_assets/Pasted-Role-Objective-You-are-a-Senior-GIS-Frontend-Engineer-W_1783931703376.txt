Role & Objective:
You are a Senior GIS Frontend Engineer. We have successfully migrated our "NextStop JGI" college bus tracking application from MapLibre to Mapbox GL JS using a custom Mapbox Studio style. However, our interactive dashboard UI (the bottom drawer showing route selection, stop lists, and live ETAs) is currently disconnected from the new map instance.
Your objective is to wire our existing UI event handlers directly to Mapbox GL JS, ensuring that all route highlights strictly follow our pre-defined Mapbox road geometries and feature custom stop popups matching our UI design.

Phase 1: Connect Route Selection (The Highlighted Blue Line)
When a user selects a route from the bottom drawer (e.g., "Pg Route"):

Use Road-Snapped Geometries: Ensure the route line rendered on the map strictly follows the road network and custom pathways defined in our Mapbox style/backend (do NOT render straight point-to-point bird-flight lines).

Dynamic Route Highlighting:

Maintain a dedicated GeoJSON LineString source named active-route-source.

Create a layer named active-route-layer styled with our UI primary color (#3b82f6, width: 5px, opacity: 0.9, rounded caps and joints).

When a route is selected in the UI, update the source using map.getSource('active-route-source').setData(selectedRouteGeoJSON).

Alternatively, if routes are already baked into our Mapbox Studio style as vector layers, use map.setFilter('your-studio-route-layer', ['==', ['get', 'route_id'], selectedRouteId]) and map.setLayoutProperty('your-studio-route-layer', 'visibility', 'visible').

Camera Auto-Fit: Automatically trigger map.fitBounds(routeBounds, { padding: 80, duration: 1200 }) so the selected route fits perfectly within the viewport.

When a user clicks a specific bus stop in the bottom list (e.g., "siddeshwar park"):

Camera Fly-To: Smoothly animate the map camera to the stop's exact coordinates using map.flyTo({ center: [stop.lng, stop.lat], zoom: 16, speed: 1.2 }).
