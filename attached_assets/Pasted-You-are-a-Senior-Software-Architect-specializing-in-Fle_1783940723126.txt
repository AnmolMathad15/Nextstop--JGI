LOCATION VERIFICATION ENGINE
---------------------------------------------------

The backend must verify every incoming GPS packet before broadcasting.

Implement:

1. Accuracy Validation

Reject GPS if:

accuracy > 30 meters

Reason:
GPS drift is common indoors.

---------------------------------------------------

2. Speed Validation

Calculate speed between two GPS packets.

Reject impossible movement.

Example:

Distance = 600m

Time = 5 seconds

Speed = 432 km/h

Reject.

Bus speed should never exceed configurable limit (e.g. 90 km/h).

---------------------------------------------------

3. Teleport Detection

Reject GPS if bus suddenly jumps more than 150 meters within a few seconds.

Mark as suspicious.

---------------------------------------------------

4. Route Verification

Every route has GeoJSON.

Calculate distance between GPS and GeoJSON.

If distance > 75m

Bus is outside route.

Raise warning.

---------------------------------------------------

5. Map Matching

Use Turf.js

nearestPointOnLine()

Snap GPS to nearest road segment.

Broadcast snapped coordinate.

Never broadcast raw GPS.

---------------------------------------------------

6. Heading Verification

Compare heading with road direction.

If bus heading differs more than 90°

Flag suspicious.

---------------------------------------------------

7. Timestamp Validation

Reject old packets.

Reject future timestamps.

Accept only timestamps within 30 seconds.

---------------------------------------------------

8. Duplicate Packet Detection

Ignore duplicate packets.

---------------------------------------------------

9. Driver Authentication

Every socket connection must contain JWT.

Reject unauthorized driver.

---------------------------------------------------

10. GPS Confidence Score
